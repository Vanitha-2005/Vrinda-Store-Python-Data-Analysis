# Vrinda Store Data Analysis using Python

## Project Overview
This project analyzes Vrinda Store sales data using Python to understand sales performance and customer behavior.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data loading and cleaning
- Missing values and duplicate checking
- Total sales and order analysis
- Sales by gender and age group
- Sales by category and channel
- State-wise and monthly sales analysis
- Charts and business insights

## Project Files
- Python analysis notebook
- Dataset files, where available

## Conclusion
This project helps identify sales trends, customer preferences, and business insights from the Vrinda Store dataset.
